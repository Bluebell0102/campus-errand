# 顺路帮 · 校园跑腿互助平台

在线访问：https://bluebell0102.github.io/campus-errand/

校内实名、赏金托管、交付码核验、信用积累的校园跑腿互助平台。纯前端可交互原型，数据保存在浏览器本地；手机版与电脑版两套布局，可在「我的 → 设置」中切换。
