# 顺路帮 · 操作手册

在线体验：https://bluebell0102.github.io/campus-errand/

## 3 分钟快速体验

按顺序点，就能走完“发单 → 接单 → 交付 → 评价 → 仲裁”的完整闭环。

1. **发一个任务**：底部点「发布」→ 选「代买物品」→ 填描述（试试输入“代签到”，会被拦截）→ 改送达地点，看建议赏金变化 → 发布。
2. **换身份接单**：点右上角头像（或「我的 → 设置」）→ 在「演示身份」里选**陈同学** → 回大厅找到刚才的任务 → 接单。接单后能看到联系方式。
3. **更新进度**：点「已取件/已买到」，进度条前进；可以在订单消息里留言。
4. **拿交付码**：切回**林同学**，打开这个任务，能看到 4 位交付码。
5. **完成交付**：再切到**陈同学**，点「当面交付」输入交付码 → 订单完成，赏金和垫付款到账，信用 +2。
6. **互相评价**：两边各评价一次。只有一方评价时，对方看不到内容（双盲）。
7. **处理纠纷**：「我的 → 设置 → 运营后台」，处理预置的一条举报和一条申诉，看信用和资金怎么变。

## 演示身份

| 身份 | 特点 | 适合体验 |
|---|---|---|
| 林同学 | 已认证，信用 128（可靠） | 默认身份，发单与接单都能做 |
| 陈同学 | 已认证，信用 156（优秀） | 作为另一端接单、接大额垫付单 |
| 王同学 | 未认证 | 看未认证时的限制，并完成实名认证（+20） |
| 赵同学 | 信用 58（受限） | 看低信用不能接单的提示 |

## 发布任务

- 先选类型，不同类型的字段不一样：快递要填取件码，代买要填垫付金额，占座只选一个地点。
- 赏金默认用建议价，会随距离、大小、时间自动变化；用 −/＋ 手动改过后就不再自动变，可点「使用」恢复建议价。
- 取件码和联系方式只有接单的人能看到，可以放心填。
- 发布后赏金会从余额里冻结。余额不够时，到「我的」点「演示充值」。

## 接单与交付

- 大厅顶部选「我正要去 …」开启顺路模式，只看顺路的单。
- 接单有门槛：要实名认证、信用 ≥60；垫付超过 50 元的单要信用 ≥100；同时最多 3 单。
- **当面交付**：向发布者要交付码，输入即完成，最稳妥。
- **无接触交付**：放到约定位置并拍照，对方确认或 24 小时后自动完成。
- 中途放弃会扣 3 分信用，任务会回到大厅。

## 我的订单

- 分「我接的单」和「我发布的」两栏，需要你处理的订单排在前面，并提示下一步做什么。
- 发布方可以「催一下」（5 分钟一次）、「加价」、「取消」；过期或取消的任务可以「再来一单」一键重发。
- 东西有问题时，在待确认状态点「有问题，申诉」，结算会暂停，交给运营处理。

## 个人中心与设置

- 查看信用分、等级、能享受的权益、每次加减分的原因。
- 「设置」里可以切换手机版 / 电脑版、换主题色、切换演示身份、重置演示数据、进入运营后台，也能找到操作手册和 PRD。

## 运营后台

- 上方看平台数据：任务总数、接单率、平均接单用时、履约率、纠纷率、平均信用。
- 举报：「核实，下架任务」会下架并扣发布者 20 分；「驳回」不做处理。
- 申诉：可展开进度记录判断；「支持发布者」退款并扣跑腿者 20 分，「支持跑腿者」放款并扣发布者 5 分。

## 常见问题

**数据存在哪？**只存在你自己的浏览器里，别人看不到；换浏览器或清缓存会回到初始数据。

**点乱了怎么办？**「我的 → 设置 → 演示身份」下方的「重置演示数据」。

**隔几天再打开，任务都过期了吗？**不会。演示数据的时间在你离开期间是暂停的，回来时任务的剩余时间和离开时一样。

**钱是真的吗？**不是，钱包和支付都是模拟的，用来演示托管和结算流程。
